# SpaceX Ships

Русскоязычный каталог кораблей SpaceX на React, TypeScript и Redux Toolkit Query. Графитовая тема, адаптивные карточки, фильтры по названию, порту и типу корабля, отдельная страница с характеристиками.

## Запуск

Требуются Node.js 24 LTS (версия указана в .nvmrc) и npm.

```sh
npm ci
npm run dev
```

Vite напечатает адрес приложения. Для проверки production-сборки:

```sh
npm run build
npm run preview
```

## API

По умолчанию запросы отправляются непосредственно на https://api.spacexdata.com/latest — документированный адрес последней версии каждого ресурса ([версионирование API](https://github.com/r-spacex/SpaceX-API/blob/master/docs/README.md#versioning)):

- POST /ships/query — каталог с фильтрами и пагинацией по 5 кораблей.
- GET /ships/:id — характеристики корабля.

Для смены сервера скопируйте .env.example в .env.local, задайте VITE_API_BASE_URL и перезапустите Vite. Переменная встраивается при сборке; сервер должен поддерживать тот же контракт API и CORS для адреса приложения. Секретные ключи в VITE-переменных хранить нельзя: они доступны браузеру.

Используется единый RTK Query API с кешированием, отменой устаревших запросов, проверкой ответа и тайм-аутом 15 секунд. Фильтры сохраняются в URL: search, port (порты разделяются символом _), type, page. Поиск применяется через 300 мс; изменение фильтра сбрасывает страницу на первую одним переходом.

**Доступность на 21 октября 2026 года:** первичные проверки GET /ships и POST /ships/query вернули HTTP 525 (ошибка TLS внешнего сервиса); повторные проверки завершились тайм-аутом через 15 секунд. Исправление приложения не восстанавливает сервер SpaceX. Резервных данных и подмены ответа в приложении нет: при сбое отображается сообщение и кнопка повторной загрузки. Из-за отсутствия CORS-заголовков у аварийного ответа браузер может показывать сетевую ошибку вместо кода 525. Успешные сценарии проверяются изолированными тестовыми ответами, которые не входят в production-сборку.

## Проверки

```sh
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
```

Можно использовать уже установленный Chrome. В PowerShell:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'chrome'
npm run test:e2e
```

Браузерные тесты запускают собственный Vite на порту 5187; порт должен быть свободен. Покрыты ширины 375, 768, 960 и 1440 px, длинные названия, отсутствие фото, навигация, кеширование, сброс фильтров, мобильная панель, Escape и удержание/возврат фокуса. Скриншоты создаются в test-results/.

Тесты API проверяют успешные и пустые ответы, HTTP 404/525, ошибки сети, невалидные JSON и структуру ответа, тайм-аут и отмену запросов.

## Стек и структура

React 19, React Router 7, Redux Toolkit 2 / React Redux 9, TypeScript 7, Vite 8 и Sass. Зависимости обновлены по npm-тегу latest; точные версии закреплены в package-lock.json.

- src/shared/api/product/shipsApi.ts — контракт и обработка запросов.
- src/pages/index — каталог, фильтры и состояние URL.
- src/pages/product — страница корабля.
- src/app/index.scss — общая тема и адаптивность; сторонние шрифты не загружаются.
- tests — модульные, интеграционные и браузерные проверки.

Для публикации используйте содержимое dist/. Хостинг должен возвращать index.html для клиентских маршрутов, включая /product/:id.
